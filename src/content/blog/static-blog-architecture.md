## 为什么选择静态博客

静态博客的核心优势是简单：

1. 内容以 Markdown 文件保存，迁移成本低。
2. 构建产物是纯 HTML，托管成本低。
3. 可以用 Git 管理历史版本。
4. 不依赖数据库，安全问题少。

## 内容结构

我会把内容分成三类：

- **周刊**：定期整理有趣的网站和工具。
- **博客**：完整成体系的长文。
- **随笔**：随时记录的碎片想法。

## 部署流程

整体流程是：

1. 本地写 Markdown。
2. 提交到 GitHub。
3. 自动构建静态网站。
4. 发布到静态托管平台。
5. 绑定独立域名。

## 后续演进

如果国内访问速度不理想，可以把同一份静态产物迁移到其他 CDN 或国内节点，不需要重写网站代码。
